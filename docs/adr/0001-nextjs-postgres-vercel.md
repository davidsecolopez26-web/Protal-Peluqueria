# Next.js con PostgreSQL en Vercel

Monolito full-stack con Next.js 14+ (App Router), TypeScript, PostgreSQL (via Vercel Postgres o Neon), y despliegue en Vercel. Elegido por: desarrollo rápido, tipo-safety end-to-end, server components para UI sin hidratación innecesaria, y plataforma managed que elimina ops.
